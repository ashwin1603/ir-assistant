01 · The problem

Investigations start with too much raw data

Manual triage costs time

Security events come from hosts and network sources, with useful clues spread across many records.

Context is easy to miss

Analysts need to connect related events, understand likely techniques, and preserve evidence.

Prioritization matters

A useful investigation view combines severity, confidence, frequency, and a readable timeline.

Project goal

Turn uploaded or collected logs into structured detections and an incident report that helps an analyst investigate.

06 · Security

Controls support safe analyst use

  • Backend role permissions and viewer command-line redaction.
  • Argon2 passwords, optional TOTP MFA, step-up authentication, and server-side logout revocation.
  • Login backoff, upload validation and encryption, download quotas, and auditable access.
  • Hash-linked audit records with integrity verification.
  • AI does not choose severity or execute responses; the analyst approves every simulated action.
The audit chain detects partial edits and tail deletion while its head remains intact. It is not an external immutable archive; a full database rewrite can recompute an unkeyed chain.
